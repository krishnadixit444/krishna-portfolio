# Krishna Dixit — Personal Portfolio

An expressive, illustration-driven personal portfolio built with React, TypeScript, Tailwind CSS, GSAP, and Lenis.

**Live Production Site:** https://krishna-portfolio-hazel-theta.vercel.app

## Features
- **Editorial Design System**: Condensed `Bayon` display typography paired with `Plus Jakarta Sans` and warm pastel-to-bright color transitions (`#F3F3E9`, `#E33529`, `#F4CED3`, `#AFD8FB`, `#2B6786`).
- **Custom SVG Illustrations**: Hand-crafted hero character illustration, interactive 5-discipline services wheel, 4-stage folder-tab process cards, and transitional geometric orbs.
- **Dedicated Case Study Routes (`/work/:slug`)**: Full editorial case studies covering Soshals Creator CRM, X Quote-Tweet Crawler, Instagram Creator Intelligence Engine, Sanctuary Living, X-Insights Extension, LabourLink System, and the MBA Automated Engineering & Doc Suite.
- **Responsive Across Desktop & Mobile**: Intentional stacked mobile compositions, expandable desktop navigation bar, and full-screen mobile drawer.

## Tech Stack
- React 18 + TypeScript + Vite
- Tailwind CSS
- GSAP & Lenis Smooth Scroll
- React Router DOM
- Vercel (SPA routing via `vercel.json`)
